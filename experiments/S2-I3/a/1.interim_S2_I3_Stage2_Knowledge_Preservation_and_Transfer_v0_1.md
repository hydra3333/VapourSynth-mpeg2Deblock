## 3. Geometry: established facts versus new empirical support

**RATIFIED / DO NOT REDECIDE:** K-02: mixed FRAME/FIELD residual transform organisation can vary per macroblock; K-03: in a frame picture, a FRAME-coded luma residual has a mid-height horizontal internal seam (between frame rows 7 and 8 of the 16x16 MB), whereas FIELD-coded residual luma has its horizontal internal layout on a field-line grid, with no seam across frame rows 7/8; both have luma internal vertical transform seam at x=8. K-07: FRAME/FIELD/NONE denotes applicable **coded residual transform geometry**, not merely presence/value of `dct_type`. NONE covers skipped MBs and effective-CBP-zero non-intra MBs. An absent `dct_type` bit does NOT automatically mean NONE. K-08: motion compensation can carry older blocking away from the current grid. Frame ownership and field-parity-aware access constrain safe pixel operations; selecting FRAME DCT does **not** authorise cross-field temporal mixing.

Terminology: a **vertical boundary** runs along fixed x and is shared by side-by-side MBs. A **horizontal boundary** runs along fixed y and is shared by stacked MBs. Code labels `neigh_h` and `neigh_v` in the Stage 1 analyzer are neighbour traversal direction, NOT line orientation. `neigh_h`: i vs i+1 -> shared vertical boundary. `neigh_v`: i vs i+mb_width -> shared horizontal boundary. This is correction M1.

### Reproducible method (as supplied in Claude's correction review)

1. Index: `read_index` from `stage2_index_reader_v0_2`; map `{0:NONE,1:FRAME,2:FIELD}`; macroblocks in raster order, `rec.iter_macroblocks()`, frame/MB grid from record header. For original/blocky luma comparison use the **blocky** index.
2. Pixels: BestSource `VideoSource`, native YUV420P8, NO pixel format conversion, plane 0; `d=abs(int16(original_Y)-int16(blocky_Y))` for corresponding decoded display frames.
3. Band masks, within MB: H rows `y % 16` in `{7,8}`; V columns `x % 16` in `{7,8}`. Interior coordinates require BOTH row and column in `{2,3,4,5,10,11,12,13}`. Exclude outer MB edges, these inner seam bands, and nearest neighbours.
4. Per transform state accumulate absolute-difference sums AND denominators (pixel counts) across all frames. `excess_percent=100*(band_mean/interior_mean-1)`. Compare within-state only; record no result for NONE if the test does not define a current coded residual seam.
5. Transform-transition recipe: side by side `(i,i+1)` for `x+1<mb_width`, stacked `(i,i+mb_width)` for `y+1<mb_height`. Count as mixed only if both coded and different. Keep coded-pair and all-pair denominators separate.
