# Visual Studio 2026 (18.11) - GitHub Copilot Free Cheat Sheet

## Before You Start
You already use GitHub repositories from Visual Studio, which means you may already have a GitHub account connected.

Cost of Copilot Free: $0

---

## Turn ON GitHub Copilot Free

### Method 1 (Easiest)

1. Open Visual Studio 2026.
2. Open any solution or project.
3. In the upper-right corner, click the GitHub Copilot icon/badge.
4. Choose **Open Chat**.
5. Enter any prompt.
6. If not already signed in, Visual Studio will offer:
   - Continue with GitHub
   - Continue with Google
7. Choose your GitHub account.
8. Complete authentication in your web browser.
9. Return to Visual Studio.
10. Copilot Free should now be active.

---

## Check Whether Copilot Is Working

Try one of these:

### Chat
Open Copilot Chat and ask:

"Explain this C++ file"

### Code Completion
Start typing code in a source file.

If Copilot is active, grey suggestions should appear.
Press TAB to accept a suggestion.

---

## Check Remaining Free Usage

1. Click the Copilot badge (top-right).
2. Look for:
   - Copilot Usage
   - Copilot Free Status
3. View your remaining allowance.

---

## Turn OFF Copilot Temporarily

### Disable Suggestions

1. Tools
2. Options
3. Search for "Copilot"
4. Disable inline suggestions or completions.
5. Click OK.

This keeps your account connected but stops Copilot assistance.

---

## Sign Out of Copilot

1. Click the account/profile icon in the upper-right corner of Visual Studio.
2. Locate your GitHub account.
3. Sign out or remove the account.
4. Restart Visual Studio if necessary.

Copilot will no longer be available until you sign in again.

---

## If You Reach The Free Limit

Nothing bad happens.

Visual Studio continues to work normally:

- Build projects
- Debug DLLs
- Use Git
- Commit changes
- Push to GitHub
- Edit code
- Compile VapourSynth plugins

Only Copilot features stop until:

- your monthly allowance resets, or
- you purchase a paid Copilot plan.
